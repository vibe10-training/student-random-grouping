# 학생 랜덤 조 구성 프로그램

학생 명단을 입력해 누락과 중복 없이 균등하게 조를 구성하는 웹 프로그램이다. 학생 명단은 브라우저 안에서만 처리되고 서버로 전송되거나 자동 저장되지 않는다.

## 실행 방법

프로젝트 폴더에서 정적 웹 서버를 실행한 뒤 `index.html`에 접속한다.

예:

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 연다.

직접 `index.html`을 여는 방식은 브라우저의 JavaScript 모듈 보안 정책에 따라 제한될 수 있으므로 로컬 웹 서버 사용을 권장한다.

## 사용 방법

1. 학생 명단을 줄바꿈 또는 쉼표로 구분해 입력한다.
2. `조 개수` 또는 `한 조당 인원` 방식을 선택한다.
3. 숫자를 입력하고 `랜덤 조 구성` 버튼을 누른다.
4. 필요하면 `다시 배정`, `결과 복사`, `인쇄`를 사용한다.

동명이인은 `김민수(3번)`, `김민수(7번)`처럼 서로 구분될 수 있도록 입력한다.

## 테스트

Node.js가 설치된 환경에서 실행한다.

```bash
npm test
```

테스트는 명단 파싱, 검증, 균등 배정, 누락·중복 방지와 결과 문자열 변환을 확인한다.
